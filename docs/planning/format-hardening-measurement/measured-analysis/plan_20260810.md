## Phase 1 — The comparison module core (TDD)

- **Goal:** `comparison.py` breakdown mode — parse journals, autopsy documents, and the
  pre-analysis document; per-arm per-candidate cause counts and rollout tallies; the
  trigger-mapping assertion; the locality refusal; the `whetstone-comparison/1` document.
- **Prerequisites:** none (all seams shipped).
- **Files:**
  - New `src/whetstone/bakeoff/comparison.py`:
    - Module docstring: what the module is, the D-arm3 determinism contract, the D6
      denominator disclosure, and the assertion contract ("reported, never reconciled").
    - `COMPARISON_SCHEMA = "whetstone-comparison/1"`.
    - `_UsageError`, `OutNotPrivate` (import the refusal from `preanalysis.refuse_published_out`
      by identity — it is the same door, `preanalysis.py:410` — or raise `OutNotPrivate` from
      `preanalysis` directly).
    - The breakdown read, strictly:
      - autopsy documents via `preanalysis.analyze_document(path)` (by identity) — per-run
        per-candidate cause counts, keyed by path stem; duplicate stems refused (the
        pre-analysis precedent, `preanalysis.py:487-495`).
      - journals via `journal.Journal(path).replay()` — per run, the steps; a missing file is
        **refused** (an arm that has not run must not read as zero rollouts); a corrupt line
        propagates `JournalUnreadable` as exit 2.
      - control discipline: per run, `any(step.probe.control is Control.INTACT ...)`, else
        refused by name (the `control.py:492` / `sweep.rankable` discipline — a run that
        never proved the harness yields no counts).
      - the pre-analysis document: parsed strictly (`schema == PREANALYSIS_SCHEMA`), carrying
        `combined.totals` (the ceiling) and `decisions` per stem.
    - **The assertion (D4):** for every autopsy record, re-derive
      `diffcheck.trigger_of_cause(cause, detail)` (imported by identity, never reimplemented)
      and compare with the pre-analysis document's `decisions[stem]` row for the same
      (index-ordered) record — `trigger` value and `inferred_truncation` flag. Any mismatch is
      written into the document as a named violation and the CLI exits nonzero. Nonzero
      `mapping_violations` in any input autopsy document are surfaced the same way. Nothing is
      reconciled.
    - Per-run, per-candidate: cause counts (from the autopsy analysis), rollout tallies via
      `report.tally(candidate, rollouts)` (by identity — "the single place each published
      figure is defined", `report.py:425`), denominator disclosures (rollout count vs autopsy
      record count), summed `generation_seconds`.
    - The document (`whetstone-comparison/1`): `schema`, `preanalysis_document`,
      `ceiling` (carried from the pre-analysis document's own numbers, never recomputed),
      `runs: {stem: {autopsy, journal, control_proven, records, rollouts, per_candidate:
      {candidate: {cause_counts, tally, generation_seconds}}}}`, `before_after` (per candidate:
      each run's cause counts side by side with the delta against the named `before` run —
      never pooled, `autopsy.py:676-677`), `violations`, and the D6 disclosures (rollout vs
      autopsy denominators; dev-subset exclusion stated for a run whose contract declares one).
      Written byte-deterministically (`json.dumps(indent=2, sort_keys=True) + "\n"`).
    - CLI `main` (exit 2, named reasons, in fixed order): `--out` refused **before anything is
      read**; missing file; duplicate stem; unparseable document; stem mismatch between
      `--journal` and `--autopsy`; control unproven; assertion violations (nonzero exit).
    - `__all__` exporting the reusable pieces.
  - New `tests/bakeoff/test_comparison.py` (RED first):
    - Synthetic fixtures: minimal `whetstone-autopsy/1` documents (the
      `test_preanalysis.py:83-105` shape), synthetic journals (the `journal._encode` field
      shape, `journal.py:134-167`), a synthetic `whetstone-preanalysis/1` document with
      `decisions` rows matching the fixture records.
    - Assert: per-run per-candidate cause counts and tallies; generation seconds summed;

## Testing strategy

- Unit (RED first, Phase 1–3): synthetic autopsy/journal/pre-analysis fixtures; every refusal
  path; the assertion's violation path; byte-determinism; the render; the door's three files,
  contract fields, token spend, disjointness, control refusal.
- Real-data (Phase 2): the two stored arms, zero violations expected, byte-identical
  re-invocation.
- Adversarial shape for this aspect (measurement honesty, not the reward): a planted trigger
  mismatch between the comparison and the pre-analysis must be **reported and refuse the run**,
  never smoothed — the test a credulous comparator would pass.
- Manual: `uv run whetstone --help`; the full suite after every phase.

## Edge cases & error handling

- Arm not run (missing journal): breakdown mode refuses; the door refuses; the committed
  declaration stands — `UNVERIFIED`-grade honesty for a measurement that was never made.
- Control unproven: refused by name; nothing becomes a count.
- Assertion violations: named in the document, nonzero exit; never reconciled.
- Duplicate stems / stem mismatch: exit 2 with the reason named.
- Stored-run denominators differ (rollout vs autopsy counts; budget-2048 14B-only; the new
  arm's dev-subset exclusion): disclosed side by side, never fused.
