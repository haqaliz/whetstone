## Edge cases & error handling

- The `_probe_check_values` helper keys on `whetstone check-probe`; the new `check-leakage`
  block needs its own keying — reuse the shape, never a shared module constant mutated.
- The two run-id tokens must be *distinct literals in the sheet and the guard* — a sheet
  that reuses one token for both runs is refused by `test_run_ids_are_operator_declared_and_
  never_historical` (values must equal the block-specific token).
- `_bash_blocks` counts bash blocks; the new `check-leakage` block raises the block count —
  only `test_after_the_night_commands_check_leakage` and the anti-vacuity door-count test
  care, and the door-count test counts door blocks only (keyed on
  "whetstone run --night"), so it is unaffected.
