## Phase 1 — Runtime dispatch (`engine_for`)

**Goal:** one function maps a runtime name to the base-only engine, by identity.

**Files:** `src/whetstone/loop/baseline.py`, `tests/loop/test_baseline_door.py`.

**Steps (RED first):**

1. Test `test_engine_for_dispatches_by_identity`:
   - `baseline.engine_for(backend.MLX) is gate.baseline_engine`.
   - `baseline.engine_for(backend.TORCH) is torch_runtime.torch_gate_engine` (import
     `whetstone.loop.torch_runtime` in the test; its module scope imports no torch).
   - `baseline.engine_for("torch-cpu") is torch_runtime.torch_gate_engine` (the legacy name
     through `backend.family`).
   - An unknown name raises `backend.UnknownRuntime`.
2. Test the module-scope walk: extend
   `test_baseline_module_imports_no_mlx_at_module_scope` to forbid `torch` as well as
   `mlx`/`mlx_lm`; the anti-vacuity assertion still demands a module-scope `baseline_engine`.
3. Implement `engine_for(name)` at the `baseline_engine` binding, importing
   `torch_runtime` inside the Torch branch; add it to `__all__`.

**Validation:** the two tests fail before the implementation, pass after; the existing suite
stays green.

**Commit:** `torch-baseline-door: dispatch the base-only engine by runtime (TDD)`

## Phase 2 — `measure` resolves, records and discloses the runtime

**Goal:** `measure` can detect or accept a `Backend`, dispatch the engine, carry the backend in
its result, and print it.

**Files:** `src/whetstone/loop/baseline.py`, `tests/loop/test_baseline_door.py`.

**Steps (RED first):**

1. Add `_MLX_BACKEND` and `_TORCH_BACKEND` `Backend` fixtures in the test module.
2. Test `test_measure_carries_the_backend_and_discloses_the_runtime`:
   - `measure(..., backend=_TORCH_BACKEND, engine=stub)` returns a measurement whose
     `.backend is _TORCH_BACKEND`.
   - `disclosure(measurement)` contains a `runtime: torch (` line naming the library, version,
     device and precision.
3. Test `test_measure_refuses_an_engine_without_a_backend`: an injected `engine` and no
   `backend` raises `ValueError` naming both, before any scoring.
4. Test `test_measure_detects_the_runtime_when_no_engine_is_injected`: monkeypatch
   `baseline.detect` to return `_TORCH_BACKEND`; call `measure` with no `engine`/`backend` and a
   stub Torch engine returned by `engine_for`; assert the stub was asked and the measurement
   carries the backend.
5. Implement in `measure`:
   - keyword-only `prefer: str | None = None`, `backend: Backend | None = None`;
   - `engine: Callable[..., Generator] | None = None`;
   - after the measured-once guard and before the recorder:
     `if engine is None: backend = backend or detect(prefer=prefer); engine = engine_for(backend.name)`;
     `elif backend is None: raise ValueError(...)`.
   - import `detect` by name (`detect = backend_module.detect`) so tests can patch it.
   - add `backend: Backend` to `BaselineMeasurement`; return it; add the disclosure line.
6. Update the test helper `_measure` to pass a default `_MLX_BACKEND` (the existing direct tests
   inject an engine, so they need a backend under the new precondition).

**Validation:** the new tests fail first; the existing measurement tests pass with the helper
change; `disclosure` tests pass with the extra line.

**Commit:** `torch-baseline-door: measure detects, dispatches and discloses the runtime (TDD)`

## Phase 3 — The backend is provenance, in the evidence and the artifact, sealed

**Goal:** a measured evidence and artifact carry the runtime; the declaration does not; the
committed declaration still reads.

**Files:** `src/whetstone/loop/baseline.py`, `src/whetstone/bakeoff/report.py`,
`tests/loop/test_baseline_door.py`, `tests/loop/test_baseline_document.py`,
`tests/bakeoff/test_baseline_report.py`, `tests/loop/test_honest_report_door.py`.

**Steps (RED first):**

1. Test `test_the_evidence_records_the_backend_and_the_runtime_versions`:
   `measure(..., backend=_TORCH_BACKEND, engine=stub)` writes an evidence document whose
   `backend` equals `_TORCH_BACKEND.recorded()`; `tool_versions` contains `torch` at the fake
   version and **not** `mlx-lm`.
2. Test `test_the_artifact_carries_the_sealed_backend`:
   render the measurement; `read_baseline_document` returns `backend == recorded`; editing only
   the `backend` block in `report.json` and re-reading refuses the seal.
3. Test `test_a_measured_artifact_without_a_backend_is_refused` (the evidence and the artifact
   paths).
4. Test `test_the_committed_declaration_reads_without_a_backend`: read
   `reports/baseline-measurement/report.json`; `measured is False`, `backend is None`,
   `series is None`.
5. Test `test_a_backend_is_not_part_of_the_series_key`: two artifacts with the same
   base/revision/held-out digest and different backends return the same `SeriesIdentity`; a
   second measurement of that series is refused by name and the stub is not asked.
6. Implement:
   - `write_evidence(..., backend: Backend)` writes `backend.recorded()` and calls
     `tool_versions(backend=backend)`; the evidence shape is still `whetstone-baseline-run/1`.
   - `_read_evidence` requires the block and validates its shape and `backend.family(name)`;
     refuse a missing/malformed block by name.
   - `build_baseline_report(..., backend: Mapping[str, Any] | None = None)` raises when
     `measured=True` and no backend; writes `backend` when given; the declaration passes none.
   - `_BASELINE_DIGESTED_FIELDS` and `_BASELINE_KNOWN_FIELDS` gain `backend`.
   - `BaselineDocument` gains `backend`; `read_baseline_document` validates and returns it for a
     measured document and requires it; the declaration returns `None`.
   - `render_artifact` passes the evidence's backend to the writer.
   - Update the test fixtures: `_document()` in `test_baseline_report.py` passes a backend;
     `_declaration()` does not; `_baseline_artifact()` in `test_honest_report_door.py` passes a
     backend; the round-trip test asserts it.

**Validation:** the new tests fail first; `tests/bakeoff/test_baseline_report.py`,
`tests/loop/test_baseline_document.py` and `tests/loop/test_baseline_door.py` green; the
committed declaration is read, never rewritten.

**Commit:** `torch-baseline-door: record the runtime in the sealed baseline provenance (TDD)`

3. Test `test_the_door_refuses_an_ambiguous_runtime`: `detect` raises `AmbiguousBackend`; exit

5. Test `test_a_render_mode_refuses_the_runtime_flag`: `--render ... --runtime mlx` is a usage

## Testing strategy

- Unit: dispatch identity, measure resolution, evidence/artifact provenance, seed/seal,
  refusals, parser surface.
- Composition: the honest-report door over a Torch-backed baseline.
- Compatibility: the committed declaration, the MLX-only path, the runbook guard.
- Full suite: `uv run pytest -q`; `uv run mypy src`; `uv run ruff check src tests`.

## Edge cases / error handling

- Engine injected without a backend → named `ValueError` before scoring.
- `detect` returns a runtime whose `family` is unknown → `_read_evidence` refuses the evidence.
- Missing/malformed backend in a measured evidence/artifact → named refusal, nothing rendered.
- A declaration with a backend → refused as contradictory.
- A same-base different-runtime artifact → same series, measured-once refusal (documented).
