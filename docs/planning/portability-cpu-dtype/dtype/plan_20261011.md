## Testing strategy

- Unit: the new exact-value test (AC1). No integration tests; the read sites are covered by the
  existing trainer/engine tests, which construct with injected stubs and never load a real dtype.
- Deterministic, no network, no model: the test reads a module constant.
- Adversarial: not applicable — this aspect is off the reward path and cannot be reached by a
  policy. State that in the commit body rather than inventing an attack.

## Environment, determinism & locality

- No env vars, no services, no weights. Nothing leaves the machine.
- Train/held-out boundary: untouched — this aspect reads and writes no task data.

## Edge cases & error handling

- A device absent from the map already raises `KeyError` at the read sites; the pin test keeps the
  map's key set equal to `DEVICE_ORDER`, so no device gains or loses a precision silently.
- No `UNVERIFIED` path: this is a constant, not an evaluation.
