## Testing strategy

- Unit tests mapped to phases above; **tests are written first in Phase 6**.
- Adversarial angle: the differential IS the adversarial pin — the predicate's exclusion set
  must equal the bakeoff's own refusal set, per direction, with reason classes never pooled
  (spec AC9). A predicate that excluded a task the bakeoff could build would be a held-out
  selection no stronger than the old one; a predicate that classified machine state would
  exclude permanently for a transient reason.
- Determinism: no network, no clock, no checkout; git objects only; fixed fixture repos.
- Commands: `uv run pytest tests/bakeoff/ -q` after each phase; full
  `uv run pytest -q` + `uv run ruff check .` + `uv run mypy src/` at the end.

## Edge cases & error handling

- Path missing at `base_commit` (the fix creates the file) — omitted, mirroring `_read`;
  if nothing remains, `fits=False` with the nothing-readable reason.
- Non-UTF-8 blob — omitted, mirroring `_read`; all-omitted → nothing-readable refusal.
- Budget boundary: `==` passes, `>` refuses (mirror `_read` exactly).
- Donor unreadable / git failure — **raises**; the caller (aspect 2's derivation) refuses by
  name. Never `fits=False`.
- Empty path set — structural `fits=False` (no non-test paths), never an exception.
- Machine-corpus absence — differential test skips cleanly (CI), never fails.
