## Testing strategy

- The guard tests are the deliverable — written first, watched RED, satisfied GREEN. No
  other test surface changes.
- The cross-pins (budget figure by identity, log-row shape, integrity sentence) are the
  anti-drift net: an amendment that silently drifted from the code or the § 9 table fails by
  name.
- Determinism: `tests/test_docs.py` reads committed documents only; no network, no clock.
- Commands: `uv run pytest tests/test_docs.py -q` per phase; `uv run ruff check .`;
  `uv run mypy src/`.
