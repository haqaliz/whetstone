## Environment, determinism & locality

- `HF_HUB_OFFLINE=1` is set by the harness itself (`run.py:538`); no env vars for this unit.
- MLX extra installed in the worktree only (`uv sync --extra mlx`); weights read from the
  primary by absolute path, never copied into the worktree.
- All evidence (runs/, transcript, journal, breakdowns) lives under the primary's gitignored
  `runs/`; nothing is committed, nothing leaves the machine (element ⑤).
- The train/held-out boundary: the five dev-subset ids are excluded from both sources before
  anything runs (`_partition`, `run.py:540-542`); the report's `ScoredDevSubset` backstop
  refuses a leak. No training occurs in this unit — the boundary cannot be crossed.
- Determinism: the analysis tools are byte-deterministic (their own suites assert re-invocation
  identity); `--recorded-on` is declared, never read from a clock; seeds/contract digests are in
  the run's provenance.

## Edge cases & error handling

| Case | Outcome |
|---|---|
| Uniform-across-candidates provisioning/checkout failure | Harness defect — halt (runbook halt 1), fix, restart from empty workspace |
| `ContractChanged` abort mid-run | Void run, no recovery (freeze seal, M8); restart per M8, stated before the run |
| Run killed mid-retry (trailing `"retry"` record) | Refused as corruption on replay, never repaired (`transcript.py:190-198`); M8 restart |
| Reused / partially-deleted workspace | Silent `UNVERIFIED`/`UNPROVISIONED` degradation; prevented by the empty-workspace rule + halt 4 |
| Verification timeout (`--timeout 900`) | `UNVERIFIED`, never FAIL (`scoring.py:117-119`); visible in the report's counts |
| Flat before/after | Pre-committed valid outcome (R-c); report states it plainly; M7 rule converts it to the fork direction |
| Nonzero `unrecognised-shape` | S1: watched-failing fixture → taxonomy correction → re-run; named divergence, not a pass |
| Mapping violation in comparison | Named violation, nonzero exit, never reconciled; S1 path |
| Unknown dev-subset id | `UnknownDevSubset` refusal before anything runs |
| Dev id reaches a scored set | `ScoredDevSubset` refusal in the report |
| Half-truth render (missing journal / unproven control / zero arms) | Report door refuses by name, exit 2 |
