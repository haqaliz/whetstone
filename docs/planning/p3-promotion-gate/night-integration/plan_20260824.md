## Testing strategy

- Happy path: held-out ids absent from rollouts and the trainable partition.
- Ledger: digest + count recorded; old-ledger tolerance.
- Byte-identity: unflagged run unchanged, contract SHA and sentence reproduced.
- Adversarial: doctored document, hand-edited membership, unknown id — each refused by name;
  regenerated-doctored smuggling proven excluded end-to-end.

## Environment, determinism & locality

- All tests use the stub engine (`engine_of`/`Answers`) — no model, no GPU, no network.
- The fixture held-out document is built by the aspect-1 writer inside `tmp_path`; the committed
  document is only referenced by tests that can skip in CI (recomputation precedent).
- Nothing leaves the box.

## Edge cases

- A held-out id that is also a declared dev id: exclusion, never refusal (dev ∩ held-out).
- An empty scored private set after both overlays: refused before freeze, by name.
- Source A is always scored in full — the held-out exclusion touches source B only; assert it.
