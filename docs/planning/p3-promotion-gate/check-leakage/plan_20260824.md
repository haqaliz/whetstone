## Testing strategy

- Core: disjoint / named-overlap differential, count over denominator.
- Reader: schema refusal, digest refusal, no-ledger refusal, empty training set, zero held-out.
- CLI: 0 / 1 / 2 exits asserted end-to-end; both sources disclosed.
- Adversarial: a version that only counts is proven to lose the differential (watched failing).

## Environment, determinism & locality

- All tests use fixture runs built by the night's stub harness (`tests/loop/harness.py` +
  `_night`) — no model, no GPU, no network.
- Nothing leaves the box; the report is printed, never written to a published path.

## Edge cases

- A leaked training set found here is evidence of an aspect-2 regression — the output's wording
  names the action ("excluded at the partition seam or the night regressed"), never merely a
  count.
- An empty training set (a zero-strict-PASS night) is disjoint by truth and the output states it;
  it is not a leak and not a refusal.
