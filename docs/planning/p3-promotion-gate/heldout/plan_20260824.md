## Testing strategy

- Rule/writer: meets-or-refuses; determinism; banding from the stratum difficulty ordering.
- Loader: every refusal by name, watched failing first.
- Document: recomputation (skips in CI), canary.
- Amendments: test_docs.py green, no proportion, no placeholder, citations exhaustive.

## Environment, determinism & locality

- The writer runs against the primary's machine corpus via absolute path; nothing is copied into
  the worktree. The committed document carries counts and membership ids only — no task contents.
- The split seed is a declared constant; recomputation is deterministic and reproducible.
- No network, no model, no GPU in any phase.

## Edge cases

- Degenerate corpus → the finding is written and committed; the loader still ships (it is the
  surface the other aspects compose).
- The document's `document_digest` refuses any hand-edit; a fully regenerated doctored document
  passes by construction — the layered defence is git history + ordering + the recomputation test,
  stated, never reconciled.
