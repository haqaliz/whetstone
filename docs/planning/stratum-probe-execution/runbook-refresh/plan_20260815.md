## Testing strategy

All tests are the existing guard suite — no new test files. The refresh's own proof is the
RED-first watch (spec AC 1), the GREEN suite (AC 2), the untouched frozen pin (AC 3), the
grep-count (AC 4), and the executability `--help` checks (AC 6). Nothing here touches the
reward, the gate, or the verifier — no adversarial tests apply; the AC2 pins are the
anti-drift guard, exercised by the existing suite and the visual diff.

## Environment, determinism & locality

- No env vars, no new tools, no weights, no network. The `--help` checks are offline and
  instant; nothing here runs a model.
- Machine-level stores (`tasks/local/`, `weights/`, `runs/`) are reached by the sheet's
  absolute paths only — nothing is copied into the worktree.
- Determinism: nothing measured in this phase; the probe's determinism is the runbook's
  own discipline (pinned contract, `--recorded-on` declared, seeded draws).
- Train/held-out boundary: this phase touches no training data and no eval set.

## Edge cases & error handling

- **The RED does not fire.** If `test_no_stale_worktree_name_survives_anywhere` passes
  after the stale-list edit, the guard is not reading the sheet it claims to guard — stop,
  do not proceed to the rename; investigate the parse helpers (identity import). This is
  the anti-vacuity failure mode and it voids the refresh.
- **A 7th/8th occurrence appears.** If grep counts differ from 7, the rename missed or
  over-shot; fix before committing (a missed occurrence = the sheet fails at night; an
  over-rename = the A2 prose was touched).
- **`--help` fails for a module.** Do not patch `src/` (out of scope, AC2-pinned) — the
  module surface is 0.6.0's, already exercised by the suite; re-check the `--project`
  target (venv present, `uv sync` done) before concluding anything.
- **The operator phases fail at night.** Not this plan's error state; the runbook's halt
  conditions govern (uniform `HarnessNotProven` → stop/fix/restart from an empty workspace;
  `ContractChanged` → run void; dead evidence quarantined by name, never deleted).
