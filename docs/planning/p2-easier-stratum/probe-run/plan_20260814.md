## Edge cases / error handling

- **Workspace reuse:** never — a fresh run is a fresh empty workspace; a partially deleted
  workspace degrades silently into `UNVERIFIED`/`UNPROVISIONED`, never loudly (the rule is
  documentation-only in code, `run.py:753-759` — the runbook states it).
- **Dead-run quarantine by name, never deleted:** the 2026-08-12 precedent
  (`runs/format-hardening-arm-evidence-dead-20260812-relative-workspace/`,
  `measured-arm/finding.md:43-45`).
- **`ContractChanged` void, not recovered:** restart = quarantine the evidence directory by
  name, fresh empty workspace, fresh journal/transcript paths in a new evidence directory,
  re-run the command unchanged apart from those paths.
- **Transcript corruption refusal:** a run killed mid-retry can leave a trailing `"retry"`
  record; replay refuses it as corruption, never repaired (`transcript.py:190-198`).
- **Stratum degenerate or tiny:** a usage error, never a vacuous pass; a small stratum is a
  finding that names the re-mint step — never a reason to widen the band after seeing the
  corpus (`prd.md:218-221`).
- **Post-run chain refusals:** each is exit 2 with the reason named and nothing written —
  missing file, duplicate run key, journal/autopsy stem mismatch, no `INTACT` probe, no
  declared decisions, published `--out` (acceptance criteria 5).
