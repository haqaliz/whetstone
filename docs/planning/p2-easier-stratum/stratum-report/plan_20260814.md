  pinned baseline of § 3 (`:126-128`), which stands unmeasured and may still be measured
  exactly once; it is not the held-out split of § 7.1, which remains open until P3. At the
  time of this amendment no count has been measured under the probe, and none is claimed here.

## Edge cases / error handling

- **The M12 one-commit's RED moment must never be committed.** The guard-red state (Phase 4
  step 1) exists only in the working tree; the single commit contains declaration + argument
  + amendment together. If the phase cannot finish in one commit (e.g. a test forces a split),
  stop and escalate — M12 fixes the ordering and is not negotiable at implementation time.
- **The door never re-renders the declaration.** Zero groups is refused by name
  (`comparison.py:1108-1112` wording); the committed declaration is only ever regenerated by
  a direct writer call, and a test asserts the door's zero-group refusal writes nothing.
- **The declaration pointer vs. the rendered pointer.** The committed declaration names
  `runs/easier-stratum-arm/`; the post-run render's `--breakdown-home` names the classifier
  counts' home as `probe-run`'s runbook declares it. Both are operator-declared inputs to a
  pure writer; the tests assert the writer renders whatever it is given, not a particular
  value.
- **`--stratum-doc` and `--breakdown-home` are strings, never parsed.** The writer must not
  touch the stratum schema or the breakdown documents — a parse would pull two other aspects'
  schemas into this one and make the render impure over files it only names.
- **A journal whose tallies carry no `N` row issue:** `_row` renders zeros over the
  denominator — the format-hardening rows already handle a candidate with `weaker_wins = 0`
  (`report.md:16, 35`); no special case.
- **The six-artifact figure scan must not be vacuous:** the disjointness test asserts the
  synthetic document's figures are non-empty (the `:1270-1273` anti-vacuity discipline) and
  that at least one existing artifact contains `N of M` figures (else the guard proves
  nothing — same discipline).
- **`PREREGISTRATION.md` guards:** the amendment contains no `%`/`percent`/`percentage`, no
  placeholder, no success threshold, no § 7 item closure — checked by `tests/test_docs.py`
  before the commit; the amendment's prose never restates a count from any report home.
