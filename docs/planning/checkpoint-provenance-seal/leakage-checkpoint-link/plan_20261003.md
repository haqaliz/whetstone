## 2. Implementation phases

### Phase 1 — The checkpoint link, in the library

- **Goal:** `run_check` can take a checkpoint and returns what it found about the link.
- **Prerequisites:** aspect 1.
- **Files:** `tests/loop/test_check_leakage_checkpoint.py` (new), `src/whetstone/loop/check_leakage.py`.
- **Change:**
  - Two new refusals, `ValueError` subclasses with operator-fixable messages, added to `REFUSALS`
    together with `sft.CheckpointUnverified`:
    `CheckpointHasNoDataset` (untrained checkpoint — "it was trained on nothing, so there is no
    dataset to compare") and `CheckpointNotThisRun` (names both digests' leading 12 hex and says the
    checkpoint was not trained on this run, so a verdict about the run says nothing about it).
  - `@dataclass(frozen=True) class DatasetLink: digest: str; sealed: bool`.
  - `LeakReport` gains `link: DatasetLink | None = None` (defaulted; the existing constructors and
    the byte-identical default output are untouched).
  - `run_check(run, heldout, checkpoint: Path | None = None)`. When `checkpoint` is given:
    call `sft.verify_checkpoint(checkpoint)` (module-scope import of `whetstone.loop.sft` is fine
    here — `check_leakage` already imports `night`; `cli.py`'s function-local rule is about `cli`);
    refuse `CheckpointHasNoDataset` if `untrained`; read the run's training-set digest from the
    already-parsed `dataset.json` document (`document["digest"]` — the same value
    `finding.md` § 5 compares; the agent confirms the key name in `_read_dataset` / `dataset.py` and
    refuses `DatasetUnreadable` if it is absent or not a str); compare strings exactly, lowercase
    hex, no normalising — a case difference is a mismatch; mismatch → `CheckpointNotThisRun`.
    **Order:** verify the checkpoint and read both digests *before* the overlap comparison, so a
    mismatch refuses even when the run is leaked (a leaked run plus another night's checkpoint must
    not reach exit 1 or 0 on the strength of a comparison about the wrong night).
    On success return the report `replace`d with `link=DatasetLink(digest, sealed=cp.sealed)`.
  - Without `checkpoint`, no new code path runs.
- **Failing tests first (criteria 2–7, 4 adversarial):** build a night directory with the existing
  helpers used by the current check-leakage tests (find them; reuse, do not duplicate); build
  checkpoints with `sft.write_checkpoint` (v2) and by hand (v1) carrying a chosen `dataset_digest`.
  Cases: v2 match → `link.sealed is True`; v1 match → `False`; mismatch → `CheckpointNotThisRun`
  with both 12-hex prefixes in the message; **leaked run + mismatching checkpoint → refusal, not a
  report** (the adversarial case); clean run + mismatch → refusal; tampered v2 (edit
  `dataset_digest`, leave digest) → `CheckpointUnverified`; untrained → `CheckpointHasNoDataset`;
  directory without `provenance.json` or missing directory → `CheckpointUnverified` (not a
  traceback); uppercase-hex recorded digest ≠ lowercase run digest → mismatch.
- **Validation:** `uv run pytest tests/loop/test_check_leakage_checkpoint.py tests/loop -q -k leak`.
- **Commit:** `check-leakage: compare a checkpoint's dataset link to the run, sealed or not (TDD)`.

## 4. Testing strategy

- Unit tests per phase, written first.
- **Adversarial:** leaked run + a checkpoint from another night must not exit 0 or 1; it exits 2. A
  tampered v2 checkpoint exits 2. A v1 checkpoint's link must never read as sealed. Each fails under a
  naive implementation (one that compared digests without verifying, or compared after the overlap
  check) and passes here.
- **Unchanged-behavior tests:** default output and exits byte-identical; `test_gate_leakage_finding.py`
  passes or skips loudly (it skips in a worktree — **run it from the primary checkout after merge**
  and say so in the landing note; do not claim it ran if it skipped).
- Manual: after merge, the operator may run `check-leakage --checkpoint checkpoints/portability-arm`
  against `runs/nights/night-001`; the expected, and only real-world, output is the "recorded, not
  sealed" line. This is the operator's step, not a test, and nothing in this unit is described as
  having done it.
- Deterministic, no network, no model call.

## 5. Environment, determinism, locality

- No environment variable. Reads JSON documents and hashes files; runs nothing.
- **Train/held-out boundary:** the command exists to protect that boundary. This aspect adds a way to
  check *which night a candidate came from*; it does not alter the identity-by-sha12 comparison, which
  keeps its stated residual (near-duplicates are not detected). A clean result still means "no shared
  task identity", never "no contamination".
- Nothing leaves the machine.

## 6. Edge cases and error handling

| Case | Outcome |
|---|---|
| `--checkpoint` absent | today's behavior, byte-identical |
| v2 match | verdict as dictated, "sealed" line |
| v1 match | verdict as dictated, "recorded, not sealed" line |
| Digest mismatch (any run verdict) | exit 2, `CheckpointNotThisRun` |
| Untrained checkpoint | exit 2, `CheckpointHasNoDataset` |
| Tampered / missing / no-provenance checkpoint | exit 2, `CheckpointUnverified` message, no traceback |
| Run's `dataset.json` has no usable `digest` | exit 2, `DatasetUnreadable` |
| Case-differing hex | mismatch, exit 2 |

There is no outcome in which a checkpoint problem yields exit 0. The command never promotes anything.
