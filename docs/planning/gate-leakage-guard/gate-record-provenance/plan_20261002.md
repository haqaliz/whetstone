## Phase 1 — Read the dataset digest from a checkpoint (RED first)
- **Goal:** one fail-closed helper returning a trained checkpoint's dataset digest.
- **Files:** `tests/loop/test_gate_provenance.py` (new, tests first), `src/whetstone/loop/gate.py`
  (next to `_checkpoint_base`).
- **Tests first:** trained fixture -> its recorded digest. **Adversarial:** a trained checkpoint whose
  `provenance.json` lacks or malforms `dataset_digest` -> a refusal in gate `REFUSALS`, never
  `""` or `None`. Untrained -> an explicit absent marker, not a fabricated digest.
- **Commit:** `gate-provenance: read a trained checkpoint's dataset digest, refuse a missing one (TDD)`

## Phase 2 — Record it; bump the schema; readers refuse the old version
- **Goal:** the record carries `candidate.training{dataset_digest, base_repo_id, base_revision}` and
  `incumbent.training` (base only, `dataset_digest` explicitly null).
- **Schema:** `PROMOTION_SCHEMA = "whetstone-promotion/2"`. `read_promotion_record` refuses
  `whetstone-promotion/1` with a message saying the record predates provenance and is never upgraded.
- **Files:** `gate.py`; tests in `test_promotion_record_n.py` and `test_gate_provenance.py`;
  `honest_report.py`, `morning.py` and their tests as failures dictate.
- **Tests first (spec AC 1-5):** fixture record's fields equal the checkpoint's values; unrecoverable
  digest -> exit 2 and **no record file written**; incumbent null is explicit; a v1 record is refused
  loudly by the record reader, morning and honest-report; decision outcomes on existing fixtures
  (promoted/rejected/UNVERIFIED) are unchanged.
- **Before editing readers:** grep `whetstone-promotion/1` across `src/`, `tests/`, `docs/`; every hit
  is updated or deliberately refused.
- **Commit:** `gate-provenance: the promotion record names what trained the candidate (schema 2, TDD)`

## Edge cases and outcomes
| Case | Outcome |
|---|---|
| Digest missing or malformed on a trained candidate | refusal, exit 2, nothing written |
| Untrained incumbent | `dataset_digest: null`, stated, not invented |
| Old v1 record read | loud refusal, never silently upgraded |
| UNVERIFIED / rejected paths | record written as before plus provenance; still non-promoting |
