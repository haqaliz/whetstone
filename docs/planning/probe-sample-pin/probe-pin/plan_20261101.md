## Edge cases

- **`pins` is the backend enable switch today.** The `backend_pins` split is mandatory; without
  it, `--probe` alone fails a `/2` ledger with "records no backend".
- **A mismatch must be exit 1, a full night exit 2.** Do not reclassify `NotAProbe`; two tests
  and the CLI help pin the refusal.
- **A `/2` ledger with `probe=2` and `--probe 16`** is a mismatch (exit 1), not a refusal; the
  ledger is still a probe.
- **A pin never turns a failing probe green.** The sample check runs before the harness fold; a
  mismatched sample on a failing probe is still not proceed.
- **The pin is a size check.** It cannot prove which 16 ran; § 10.26 and the sheet guard own
  the identity. Do not add an id list to the ledger.
