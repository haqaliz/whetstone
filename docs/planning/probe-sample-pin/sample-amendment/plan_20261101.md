## Edge cases

- **The bullet block is the only place the sample is named.** The dev ids appear later in the
  amendment; the block extraction must stop at "Plus the one public task", or the dev ids enter
  the set and the test fails.
- **The local ledger is committed but the manifests are not.** The test derives ids from the
  ledger, not from `tasks/local/`; a worktree without the user's manifests still runs it.
- **A corpus change.** Adding a task to the committed ledger changes `survivors` and fails the
  test until § 10.26 is updated. That is the intended guard: the sample is pinned before the
  probe.
- **No numbers are measured.** The only counts in the amendment are the deterministic 16, 272
  and 64; no yield, delta or model claim.
