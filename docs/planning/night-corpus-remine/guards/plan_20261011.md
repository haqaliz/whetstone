## 5. Environment, determinism, locality

- **Offline.** No network, no model, no `mlx`, no weights, no GPU. Every guard runs against
  synthetic fixtures and `tmp_path`; `uv run pytest` is the whole environment. The injected miner
  performs no provisioning, so no warm cache is needed.
- **Determinism.** AC-G1 injects a pure miner and compares two runs' **written** `dataset.json` and
  `train.jsonl`; the existing night determinism (`test_night.py:190-215`) and the sampling basis
  (`src/whetstone/loop/sampling.py:103-122`) are unchanged and asserted green unedited.
- **Locality.** The re-mine root is asserted distinct from, and not nested under, the donors' roots;
  the committed held-out document is asserted byte-identical; the donors' roots (when present) are
  asserted unwritten. Nothing under `tasks/` is created or modified by any guard.
- **Train/held-out boundary.** The collision test is the boundary's own proof: a minted task whose
  identity equals a held-out member's is excluded, and the identity detector that would catch it is
  proven live.

## 6. Edge cases and error handling

| Case | Expected behaviour | Where |
|---|---|---|
| Two re-mine nights, one donor state + seed | byte-identical `dataset.json` and `train.jsonl` | `test_remine_guards.py` (AC-G1) |
| The injected miner's `existing`/`seed` | equal across the two runs | `test_remine_guards.py` (AC-G1) |
| Re-mine over an unchanged corpus | not asserted as determinism — anti-vacuity requires the re-mined id drawn | `test_remine_guards.py` |
| Committed held-out document across a re-mine | byte-identical; `membership` + `document_digest` named on failure | `test_remine_guards.py` (AC-G2) |
| `remine_out` under `tasks/local/donor-a|b` | the guard asserts distinct and not nested (a *test* failure, not a runtime refusal) | `test_remine_guards.py` (AC-G3) |
| Machine-level donor roots absent (CI) | skip with a named reason, never a false green | `test_remine_guards.py` (AC-G3), `test_heldout_document.py:100-109` |
| `check-leakage` on a re-mine dataset | `clean`, source-B examples ≥ 1, overlap `()` | `test_remine_guards.py` (AC-G4) |
| Dataset with no source-B example | `NothingCompared` raised — the anti-vacuity the guard avoids | `check_leakage.py:115-123` |
