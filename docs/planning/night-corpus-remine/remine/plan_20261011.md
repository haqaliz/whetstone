     `def trailing_sha(task_id: str) -> str: found = _SHA12.search(task_id); return
     found.group(0) if found else task_id` — tolerant, never raising, so synthetic harness ids
     (`tests/loop/harness.py:106-122`) do not refuse (spec Open questions).
   - `def corpus_shas(tasks: Sequence[Task]) -> frozenset[str]` returning
     `frozenset(trailing_sha(task.task_id) for task in tasks)`; import `Task` from
     `whetstone.verify.task`. This is the `existing` set `run_night` builds.
   - `@dataclass(frozen=True) class DonorOutcome:` with `label: str`, `donor: Path`,
     `minted: tuple[str, ...]`, `rejected: tuple[tuple[str, str], ...]`, `absent: str = ""`.
   - `@dataclass(frozen=True) class RemineReport:` with
     `minted: tuple[tuple[str, str], ...]` and `donors: tuple[DonorOutcome, ...]`.
   - `def remine(donors, *, out, limit, scratch, timeout, existing, seed=None, clock=utc_now)
     -> RemineReport:`:
     ```
     out = Path(out); scratch = Path(scratch)
     accumulated = set(existing)
     pairs: list[tuple[str, str]] = []
     outcomes: list[DonorOutcome] = []
     for label, donor in donors:
         try:
             report = mine(Path(donor), out, label=label, limit=limit,
                           scratch=scratch / label, tasks_root=out, timeout=timeout,
                           seed=seed, clock=clock, skip=frozenset(accumulated))
         except (MintFailed, NotProvisionable) as exc:
             outcomes.append(DonorOutcome(label, Path(donor), (), (), str(exc)))
             continue
         minted = tuple(m.task_id for m in report.minted)
         accumulated.update(trailing_sha(task_id) for task_id in minted)
         pairs.extend((task_id, label) for task_id in minted)
         outcomes.append(DonorOutcome(label, Path(donor), minted,
                                      tuple((r.sha, r.reason) for r in report.rejected), ""))
     return RemineReport(minted=tuple(sorted(pairs, key=lambda pair: pair[0])),
                         donors=tuple(outcomes))
     ```
   - Module docstring: M1 incrementality, M2 training-only root (`tasks_root=out` keeps the
     miner's ledger/recipes inside it), M4/M7 no-op discipline, offline.
   - `__all__` naming `DonorOutcome`, `RemineReport`, `corpus_shas`, `remine`, `trailing_sha`.

- **Synthetic donor fixtures.** The miner's donor is
  `tests/fixtures/repos/donor.py` (`build_donor`, `DONOR_HISTORY`, `commit_shas`); packaging is
  `tests/fixtures/repos/locked.py` (`locked_project_files`, `locked_history`) — the same pair

  `src_layout_history` is available if a src-layout donor is wanted; not needed here.
- **The night harness.** `tests/loop/harness.py` (`corpus`, `weights`, `pool`, `Answers`,
  `engine_of`, `solving_answers`, `posed`) and the `_night` helper
  (`tests/loop/test_night.py:85-121`, imported as `from loop.test_night import _night`). The
  harness runs with **no `mlx`** via injected `engine`/`trainer`/`seeder`/`runtime`
  (`tests/loop/__init__.py`).
- **Fast unit tests inject the miner.** `tests/loop/test_remine.py` monkeypatches
  `whetstone.loop.remine.mine` (the module attribute) and
  `tests/loop/test_night_remine.py` monkeypatches `whetstone.loop.night.remine`; both are
  cross-platform and pay no provisioning. This is the primary coverage for M1/M2/M4/M7 logic.
- **One real donor, once.** Only Phase 5 pays real mining, `limit=1`, macOS-only, skipped

- **Exact targets.**

  - `uv run pytest tests/loop/test_night_remine_integration.py -q` (Phase 5, macOS)

## 5. Environment & secrets

- **Offline.** The re-mine reaches no network: `git` reads the donor's local history
  (`src/whetstone/tasks/donor.py:1-6,112-143`), `uv sync --frozen --no-install-project
  --offline` provisions from the donor's lock (`environment.py:236-254`), and every pytest run
  is inside the macOS Seatbelt sandbox. No secret, credential or token is involved anywhere.
- **Warm uv cache is a precondition.** A cold cache refuses every candidate `NotProvisionable`
  with the `WARM_REMEDY` text (`environment.py:557-585`). Warm it once with a network via
  `whetstone warm-cache --donor <path>` (the operator's separate step; `cli.py:31-36`). In CI,
  `tests/conftest.py` points every `uv` subprocess at the committed wheelhouse
  (`UV_FIND_LINKS`), so the suite's own installs do not depend on the machine's cache.
- **Platform.** Mining's pytest runs under the Seatbelt sandbox, which is macOS-only; the
  integration phase and `tests/test_mine_cli.py` skip elsewhere (`test_mine_cli.py:40-43`).

## 6. Edge cases & error handling

| Case | Expected behaviour | Where |
|---|---|---|
| Donor has no un-minted candidates | `remine()` returns `minted == ()`; night proceeds; ledger `remined == []` (present, empty) | `remine.py`; `night.py` block |
| Donor absent / not a git repo | `mine()` raises `MintFailed`; `remine()` catches, records `absent`, continues | `remine.py`; `mine.py:184-190` |
| Cold cache / unprovisionable | `mine()` returns empty `MintReport` (per-candidate `NotProvisionable` caught, `mine.py:216-220`); a wholesale `NotProvisionable` is caught at the `remine` boundary | `mine.py:216-220`; `remine.py` |
| `limit` reached | `mine()` breaks at `limit` (`mine.py:198-199`); the re-mine never exceeds it | `mine.py:197-218` |
| Donors/labels mismatched | `USAGE_ERROR` naming `--remine-label`, before the loop runs | `cli.py:1053-1111` |
| `--remine` without out/limit | `USAGE_ERROR` naming the missing flag | `cli.py:1053-1111` |
| `--remine-limit 0` | `USAGE_ERROR` (`run_mine` precedent, `cli.py:1011-1017`) | `cli.py` |
| `remine_out` already in `--tasks` | not appended twice; loaded fresh so the night sees the new tasks; `roots` counts the deduped union | `night.py` block |
| Same sha across two donors | the accumulated `skip` prevents the second donor re-minting it | `remine.py` |
| Synthetic ids not ending in 12 hex | `trailing_sha` falls back to the whole id; no refusal | `remine.py` |
| No re-mine flags | `remined is None`; no extra load; `roots == len(tasks)`; byte-identical | `night.py`; `record` |
| Empty `donors` sequence | `RemineReport(minted=(), donors=())`; `run_night` does not call it | `remine.py`; `night.py` |

## 7. Agent execution notes

- **Checkpoints.** After each phase: the phase's exact pytest target green, `uv run ruff check`
  and `uv run mypy src` clean, then commit with the phase's message. Do not proceed on red.
- **Likely-iteration areas.**
  - The `TaskSet(remined=...)` keyword in Phase 3 will not compile until `record`'s field
    exists (`../record/spec.md:31-43`) — sequence `record` first or co-land.
  - The `roots=len(loaded_roots)` change (`night.py:377`) may collide with `record`'s
    byte-identity fixture if it pins `roots`; confirm before Phase 3's GREEN.
  - `monkeypatch.setattr(module, "mine"/"remine")` must target the **importing** module
    (`whetstone.loop.remine.mine`, `whetstone.loop.night.remine`), not the source module, or the
    patch is invisible.
  - The `_night` helper always builds a synthetic corpus; overriding `tasks` and injecting
    `answers={}` is the way to run a re-mine night cheaply in Phase 3.
  - The synthetic harness ids do not end in 12 hex; if a test builds `existing` from them, use
    the tolerant `corpus_shas`, never a raising helper.
- **Ambiguities that could block implementation** (also in the spec's Open questions):
  1. **The `record` seam.** `../record/spec.md:68-84` expects `run_night(remined=...)` as an
     **input** with `cli.run_night` supplying the pairs; this plan has `run_night` compute
     `remined` internally and pass it straight to `TaskSet`. **Confirm before Phase 3** whether
     the `record` aspect keeps a defaulted-`None` `run_night` parameter (harmless, unused by the
     re-mine path) or drops it.
  2. **`roots` count for a flagged night.** This plan uses the deduplicated union
     (`len(loaded_roots)`); confirm the `record` byte-identity fixture does not pin the re-mine
     case to `len(tasks)`.
  3. **`NotProvisionable` at the `remine` boundary.** This plan catches it (AC7's injected-miner
     shape); confirm it should not instead be folded into `MintFailed`.
  4. **`remine` seed.** This plan passes `seed=run_seed`; `None` (oldest-first) is equally
     deterministic. Confirm the intended determinism statement for M8.
