## Phase 4 — the budget is not a comparability key (AC1.5)

- **Files:** `tests/loop/test_backend.py`, `tests/loop/test_gate.py`.
- **Steps:**
  1. Add a test asserting `"draws"` (and `"k"`) is not a key of `Backend(...).recorded()`.
     Run against the current `Backend`: it should already pass — the value of the test is to

- **Commit:** `raise-k: the draw budget is not a gate comparability key (TDD)`

## Edge cases & error handling

- Do not touch `sampling.TEMPERATURE`/`TOP_P` or the `SAMPLER` string.
- The probe's internal draw narrowing (`ledger.py:226`) is not a flag and must not be broken.
- `K` stays a module constant; no function gains a `draws`-setting parameter beyond the
  existing `run_night(draws: int = K)` seam (used by tests only).
