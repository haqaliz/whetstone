# Plan — `locatability-finding` (2026-09-27)

**Spec:** `spec.md` (this directory) — the classification rules there are fixed and are the
contract; this plan does not restate or vary them. **PRD:** `../prd.md` § 4.2.

## 1. Context

- New module `src/whetstone/bakeoff/locatability.py`, stdlib only, modelled on
  `bakeoff/attribution.py` (same inputs, same temp-checkout pattern in `main`, same "a question
  that could not be asked is named, not guessed" discipline).
- Reuses by identity, never reimplements: `patch.extract_patch`, `transcript.Transcript.replay`,
  `journal.Journal` replay, `tasks.manifest.load_tasks`, `verify.repo.materialise`.
- Off the reward path. Nothing under `verify/`/`tasks/` changes or imports it.
- Train/held-out: reads a finished arm's evidence only; writes nothing to it. No held-out task is
  trained on or even scored — this is read-only diagnosis. Locality: all local.

## 2. Phases

### Phase 1 — the hunk walk (pure)

- **Files:** `tests/bakeoff/test_locatability.py` (new), `src/whetstone/bakeoff/locatability.py`.
- **RED:** tests for the lenient walk: path from `+++ b/x` / `/dev/null` → `---` side; counts
  ignored (a wrong-count hunk yields its full body); empty line read as empty context; `\` lines
  skipped; any other bare line ends the hunk; old side = context + removed, joined with `\n`.
- **GREEN:** `walk(diff: str) -> tuple[Hunk, ...]` with `Hunk(path, old_side)`.
- **Commit:** `Walk a refused diff leniently, to ask what it quoted (#64)`

### Phase 2 — per-hunk and per-rollout classes (pure)

- **RED:** spec criteria 1–3 and 5: `classify_hunk(old_side, file_text | None, path)` over
  in-memory strings (`NO_FILE`, `EMPTY`, `INVENTED`, `AMBIGUOUS`, `LOCATABLE`); `classify_rollout`
  worst-of ordering; `EMPTY` neutrality; `DRIFT` on indentation-shifted text only, class unchanged.
- **GREEN:** enums `HunkClass`, `RolloutClass`; functions above; `read: Callable[[str], str | None]`
  injected so the pure layer never touches disk.
- **Commit:** `Class a refused diff as locatable, invented or ambiguous (#64)`

### Phase 3 — the decision and the checkout reader

- **RED:** criterion 6 (decision arithmetic incl. exact half = NO-GO, UNCLASSIFIED in denominator);
  criterion 4 (absolute / `..` path → `NO_FILE`, a sentinel file outside a tmp checkout is never
  read); criterion 9 (only `NOT_APPLIED` journal rows enter).
- **GREEN:** `decide(classes) -> Decision`; `checkout_reader(root: Path)` that resolves the path,
  refuses anything not strictly inside `root` (after `resolve()`, so symlinks escaping are refused),
  returns `None` for missing files.
- **Commit:** `Decide GO or NO-GO by the rule fixed before the run (#64)`

### Phase 4 — the command

- **RED:** criteria 7, 8, 10. A CLI test builds a real tiny donor repo (reuse
  `tests/bakeoff/test_attribution_cli.py`'s fixture helpers), a journal and a transcript with
  three rollouts (one locatable, one invented, one `NOT_SOLVED` that must be ignored), runs
  `main([...])`, asserts exit code, output JSON (schema `whetstone-locatability/1`, sorted keys),
  byte-identity across two runs and under two `PYTHONHASHSEED` values (subprocess). Refusals:
  missing transcript, missing journal, candidate absent, empty population → exit 2, nothing written.
  Import guard: the module's AST imports none of `mlx`, `torch`, `whetstone.bakeoff.run`,
  `whetstone.bakeoff.scoring`; add it to whatever list `tests/test_no_inference_on_reward_path.py`
  and the bakeoff one-way-import test walk, if they enumerate modules.
- **GREEN:** `main(argv)` — `--transcript`, `--journal`, `--candidate`, `--tasks` (repeatable),
  `--out`; materialise each needed task once into a `TemporaryDirectory`; a task that cannot be
  loaded or materialised → its rollouts `UNCLASSIFIED`.
- **Commit:** `A command that asks the stored arm the question, offline (#64)`

### Phase 5 — run it, write the finding (⛔ human checkpoint after)

- **Command** (absolute paths, from the worktree):
  ```
  uv run python -m whetstone.bakeoff.locatability \
    --transcript /Users/aliz/dev/at/whetstone/runs/larger-base-arm-evidence/transcript.jsonl \
    --journal    /Users/aliz/dev/at/whetstone/runs/larger-base-arm-evidence/journal.jsonl \
    --candidate  mlx-community/Qwen2.5-Coder-32B-Instruct-4bit \
    --tasks /Users/aliz/dev/at/whetstone/tasks/local/donor-a \
    --tasks /Users/aliz/dev/at/whetstone/tasks/local/donor-b \
    --out /Users/aliz/dev/at/whetstone/runs/patch-representation/locatability-32b.json
  ```
- **Sanity checks before reading the decision:** population equals the arm's `patch apply` count
  in `reports/larger-base/report.md`; `UNCLASSIFIED` is zero or explained. A mismatch stops the
  phase — it is a join bug, not a finding.
- Write `docs/planning/patch-representation/finding.md`: decision, population size, the rules'
  location, `DRIFT` stated in words, the proxy caveat (PRD R6), pointer to the gitignored JSON.
- **Commit:** `Record whether the pinned base's refused diffs quote real code (#64)`
- **⛔ Checkpoint:** show the operator the finding. GO → plan `search-replace-contract`. NO-GO →
  finish the unit with aspects 1–2 only.

## 3. Edge cases and outcomes

| Case | Outcome |
|---|---|
| Transcript has no graded record for a journal `NOT_APPLIED` key | `UNCLASSIFIED` (evidence missing), in the denominator |
| File not UTF-8 | `NO_FILE`? **No** — `UNCLASSIFIED` with a reason; the question could not be asked |
| Donor repository missing on this machine | every rollout of that task `UNCLASSIFIED` |
| Diff names two files, one missing | worst-of → `NO_FILE` |

## 4. Agent notes

- The spec's rules are frozen once Phase 5 runs. If a phase 1–4 test reveals a rule is ambiguous,
  stop and amend the spec **before** Phase 5, in its own commit.
- Phase 5 reads the primary checkout's `runs/` and `tasks/local/` by absolute path; never copy them
  into the worktree (`whetstone-worktrees`).
