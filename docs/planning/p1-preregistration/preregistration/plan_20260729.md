## 0. A note on parallelism, stated rather than faked

`whetstone-begin-fast` asks for one agent per **independent** plan task. These tasks are **not
independent**: nine of the ten guards land in the single file `tests/test_docs.py`, and the
document itself is one file. Dispatching agents in parallel onto the same two files would produce
conflicts, not throughput. So the plan is **sequential**, and the fan-out is spent where it is
actually independent: a final adversarial review pass by an agent that did not write the code,
against the PRD's acceptance criteria. Recorded here so a reader does not mistake a sequential
plan for a skipped step.

## Step 1 — RED: the content guards (T1–T6)

Add six guards to `tests/test_docs.py`, in house style (long sentence-cased names, a docstring
naming the incident each guard prevents, `assert cond, (f"...\n\nWHY THIS IS A FAILURE: ...")`).

Reuse the module's existing `_read`, `_flat` and `REPO_ROOT`. **Do not** use `_section` on the
document's final section — it slices to the next `\n## ` and raises `ValueError` on the last one
(`understanding.md` § 7.6). `_read` raises `FileNotFoundError` rather than failing with a message,
so T1 asserts `is_file()` explicitly first, in the style of `tests/test_tasks_layout.py:133`.

| Test | Asserts |
|---|---|
| `test_the_preregistration_exists_and_carries_its_sections` | `(REPO_ROOT / "PREREGISTRATION.md").is_file()`, then each of the nine `## ` headings individually |
| `test_the_preregistration_contains_no_placeholder` | none of `TO-BE-FILLED`, `TBD`, `TODO`, `FIXME`, `XXX`, `???`, `_____` |
| `test_the_preregistration_states_no_figure_about_a_model` | no `%`, no `percent`, no `percentage` (case-insensitive) — **and** the sentence stating that rule is present, so the ban is documented rather than accidental |
| `test_the_preregistration_carries_the_roadmap_section_6_contract` | headline is source B; both published together; disagreement is a finding; the public-gain-with-private-flat signature |
| `test_the_preregistration_carries_every_disclosure` | five disclosures, **each asserted separately** so one cannot mask another: self-selection (incl. the refused `rereflect` mitigation), source A's one-of-300, the two cheat residuals + the write-not-read bound, source B's data locality, timing-control-not-independence-control |
| `test_the_preregistration_names_what_is_open_without_guessing_it` | held-out split, *R*, and the base named open; the amendment rule present; **the exception clause** — an amendment may close an open item and may never introduce a success threshold (PRD 🔴 #3) |

**Run:** `uv run pytest tests/test_docs.py -k preregistration` → expect **6 failed**, the first on
`is_file()`. Record the failure output; a guard nobody watched fail is not trusted
(`CONTRIBUTING.md:56-60`).

## Step 2 — GREEN: write `PREREGISTRATION.md`

Root level (per D5's lesson: the pre-registration lives where the claim is published). Nine
sections per PRD § 5. Content obligations R4–R9. Two rules govern the prose:

- **Every claim is grounded** in a committed file, cited `file:line`. The status section states
  only what is checkable in this tree.
- **Illustrative examples use placeholder letters**, never plausible digits — a fabricated-looking
  number in this document is the failure it exists to refuse.

Resolutions from the PRD's self-critique, all landing here:

- 🔴 #1 — § 4 states the no-figure rule in words, so the mechanical ban reads as deliberate.
- 🔴 #2 — § 9 gives the exact `git log` incantation proving this file's commit predates every
  report, because the test can only prove co-existence.
- 🔴 #3 — § 8's amendment rule names the threshold exception explicitly.
- 🟡 #4 — § 7 states what happens if the corpus cannot support a held-out split: that outcome is
  itself the published finding.
- 🟡 #5 — § 3 defines "measured once, re-measured never" operationally: which inputs are pinned,
  and what a change to one does to the series.

**Run:** the same six tests → expect **6 passed**.

## Step 3 — RED → GREEN: the ordering guard (T7)

The guard with real teeth, and the one that would otherwise pass vacuously — `reports/` does not
exist today, so a naive `if (root / "reports").exists()` assertion proves nothing.

1. Extract a module-level helper `_report_without_preregistration(root: Path) -> list[str]`
   returning the offending report paths (empty when the ordering holds).
2. **Watch it fail against a synthetic tree**: `tmp_path` with `reports/baseline/report.md` and no
   `PREREGISTRATION.md` → non-empty; the same tree with the file added → empty. These two are each
   other's controls, the pattern `tests/test_tasks_layout.py` uses deliberately.
3. Then assert it over the real `REPO_ROOT`.
4. **The docstring states the guard's limit honestly**: it proves co-existence in a working tree,
   not temporal ordering. One commit adding both would pass. The temporal claim is verifiable by
   `git log`, and § 9 of the document says how. Belay had to write a self-indicting section after
   making the inverse mistake; this states the bound up front instead.

**Run:** `uv run pytest tests/test_docs.py -k report` → 3 passed (two controls + the real tree).
