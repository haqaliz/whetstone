## Testing strategy

- Pure-function tests for the writer (declaration + measured + refusal + determinism),
  adversarial for the guard (planted artifact fails; a silent list extension is refused).
- The door's refusals are each asserted exit 2 with nothing written — a half-truth render is
  the failure mode.
- Identity reuse asserted `is` — the by-identity discipline of every prior aspect.
- No network, no model, no wall-clock anywhere in this aspect.

## Edge cases

- The declaration artifacts must hold no figure in any spelling (the writer generates them;
  the guard scans them).
- `--render-larger-base-report` with `--render-report`/`--render-stratum-report` is refused
  (mutual exclusion in effect, like the existing two).
- The mode refuses zero arms even when the declaration exists — the declaration is never
  re-rendered by the door.
