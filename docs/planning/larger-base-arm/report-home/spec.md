# Spec — report-home (larger-base-arm)

**Written:** 2026-08-15. **PRD:** `docs/planning/larger-base-arm/prd.md` (requirements 6–9, 13;
acceptance criteria 4–7, 10).

## Problem slice

The arm's figures need a published home that is honest about what it is: a **new series** —
the same hardened contract (§ 10.4) and the same declared task set as
`reports/format-hardening/`, under a **changed pinned input** (model revision,
`PREREGISTRATION.md:131-132`). Per § 3, a change to any pinned input invalidates the series,
and per the § 10.4/§ 10.5 precedent each new series gets its own home, a one-home-guard
admission ground, and a Type 2 amendment. The home's committed state is the declaration,
generated by the writer, never hand-typed.

## In scope

- `report.build_larger_base_report` / `write_larger_base_report`: the third writer, schema
  `whetstone-larger-base-report/1`, reusing `_row`, `_over`, `tally`, `_contract_fields`,
  `_contract_block`, `_counts` **by identity** (imported, never copied, asserted `is`).
- The report door's third mode `--render-larger-base-report` in `comparison.py`, in the
  stratum mode's shape: exactly one arm group, `build_contract_arms` reused unchanged, the
  named refusals, mutual exclusion with the other two modes.
- `reports/larger-base/`: declaration-only committed artifacts (report.md / report.json /
  cost.json), generated by the writer — no count, no contract fields, "**No count is

- The one-home guard's third admission ground in **both** docstring twins
  (`tests/bakeoff/test_report.py:1453-1515` and
  `tests/bakeoff/test_transcript_locality.py:73-129`): the changed-candidate-set argument,
  the artifact list extended from nine to twelve, the planted-overlap control proved able to
  fail.
- `PREREGISTRATION.md` § 10.6 (Type 2, dated 2026-08-15) + amendment log row; nothing above
  § 10 edited, no placeholder, no proportion in any spelling (`tests/test_docs.py`).
- `CLAUDE.md` status refresh (landing commit).

## Out of scope

- Any change to `run.py`'s surface, `verify/`, `patch.py`, `attribution.py`, or the existing

## Acceptance criteria (tests written first, `CONTRIBUTING.md:56-60`)

1. The writer is pure and deterministic: same inputs → byte-identical output; `tallies`
   without a `contract` refused; the declaration branch (no tallies) renders the
   "No count is measured here: the arm has not run." sentence and no figure.
2. The writer's reuse is by identity: the tests assert the shared helpers
   (`_row`, `_over`, `tally`, `_contract_fields`, `_contract_block`, `_counts`) are the
   report module's own objects (`is`), never copies.
3. The door mode appears in `comparison.py --help`; `--render-report` and
   `--render-stratum-report` are untouched (their tests unchanged-GREEN); the three modes
   are mutually exclusive (two flags together → exit 2, nothing written).
4. The door mode refuses by name: zero arm groups, misaligned groups, two groups, missing
   required flags (`--breakdown-home`, `--recorded-on`, `--out`), each exit 2 with nothing
   written; a missing-journal / empty-journal / no-INTACT-control arm refuses via
   `build_contract_arms` unchanged.
5. The committed declaration artifacts under `reports/larger-base/` equal the writer's
   declaration output (a test re-renders and compares), and hold no figure in any of the
   three artifacts.
6. The one-home guard twins pass with the twelve-artifact list; a deliberately planted
   artifact under `reports/` fails the guard; both docstrings carry the changed-candidate-set
   argument; the opposite-sign twin in `test_transcript_locality.py` is in lock-step.
7. `tests/test_docs.py` GREEN: § 10.6 present and dated, its amendment log row present, no
   placeholder, no proportion in any spelling; nothing above § 10 edited.
8. AC2 pins hold: `src/whetstone/verify/`, `patch.py`, `attribution.py` byte-identical to
   `origin/master`; `uv run ruff check .` and `uv run mypy src/` exit 0; full suite green.

## Dependencies & sequencing

- Independent of the `runbook-and-guard` aspect; both may be planned/implemented in
  parallel, each in its own commits.

  the writer, never hand-typed).
- § 10.6 must be committed before the arm runs (the operator phase), but no test depends on
  the run having happened.
