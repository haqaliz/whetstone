## Testing strategy

- All assertions are structural on the runbook's text via the identity-imported parse
  helpers — no network, no model, no wall-clock.
- The RED is the adversarial half: a stale name surviving the refresh must fail the suite.
  The green half: the positive properties are name-agnostic, so the stale-list edit is the
  only falsifiable change — that is why it is watched RED first.
- `tests/test_probe_runbook_guards.py` and `tests/test_runbook_guards.py` are frozen pins:
  byte-untouched, still GREEN.

## Edge cases

- The dev-overlay ids must resolve against the primary's corpora (they were declared for
  the full set by the measured arm — verify, don't assume).
- The `--stratum` flag must appear nowhere in the new sheet (anti-vacuity asserts its
  absence; the probe's vacuous-overlay history is prose, not commands).
- N and the headroom are runbook-declared constants, decided at run time — the guard
  asserts the rule is present, never its values.
