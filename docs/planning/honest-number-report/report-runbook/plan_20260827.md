## Edge cases (from the spec)

- The sheet is committed **before** the render — it must hold no figure in any spelling;
  the guard enforces it.
- The guard's flags pin against aspect 3's parser by identity: a later parser change fails
  the sheet that still quotes the old flag — the discipline, not a bug.
- One worktree name only — the sheet must not name both the primary and a worktree.
