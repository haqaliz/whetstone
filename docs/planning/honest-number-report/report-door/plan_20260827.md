## Edge cases (from the spec)

- `bool` counts are rejected by the readers (aspect 1 / baseline loader) — the door never
  re-validates; it composes.
- An UNVERIFIED render must not contain the headline shape `+N of M held-out` — asserted by
  grep, not only by `\d+ of \d+`.
- The door's `--heldout` is a pointer it never parses (the comparison.py `--stratum-doc`
  precedent) — the series check runs on the documents' own digests, not on a re-read.
