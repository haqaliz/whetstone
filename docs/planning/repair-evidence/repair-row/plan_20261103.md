Add `Recording.generate_repair`:

```python
def generate_repair(self, prompt: str) -> str:
    """Record a repair draw under the task the frozen prompt poses; delegate if unfrozen."""
    task_id = self.contract.posed.get(prompt_hash(prompt))
    if task_id is None:
        return self.inner.generate(prompt)
    completion = self.inner.generate(prompt)
    self.transcript.append(
        Transcribed(
            candidate=self.candidate,
            task_id=task_id,
            prompt_sha256=prompt_hash(prompt),
            prompt=prompt,
            completion=completion,
            attempt=1,
            decision="repair",
        )
    )
    return completion
```

## Edge cases

- **A repair prompt not in the frozen contract.** `Sealed` raises `ContractChanged` before
  `_record`; no row. The `Recording` path delegates unrecorded, mirroring `generate`.
- **The first `"graded"` row stays.** The transcript says what was decided when the row was
  written; the repair rows follow. Do not delete or rewrite the graded row.
- **A repair that is `NO_DIFF`.** The repair row records the completion; `score` sets the final
  outcome to `NO_DIFF` (unless a later repair is `NOT_SOLVED`). The last row is still the final
  completion; the journal's `Rollout` is the verdict.
- **`--repair 0`.** No `generate_repair` call; the transcript is byte-identical.
- **Unknown decision.** `Transcribed.__post_init__` raises `ValueError`; `replay` wraps it as
  `TranscriptUnreadable`; never a silent "decided" row.
- **The seven-field codec.** Do not add a field; `test_transcript.py`'s exact-field test stays.
