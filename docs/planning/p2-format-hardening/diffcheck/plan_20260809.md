## Edge cases / error handling

- A record with `decision == "retry"` as the last record for a key is impossible in the live
  run (a retry means a following record) — assert it in the replay test as a corruption
  shape (`TranscriptUnreadable`-adjacent, not silently repaired).
- `classify_completion` raising on unexpected input: propagate — a classifier that guesses
  is a classifier whose verdicts can't be trusted (`patch.py`'s and `transcript.py`'s
  raise-don't-skip discipline).
- Non-ASCII/CRLF completions: the validator is text-pure (the autopsy's own rules handle
  them); fixture one CRLF case.
