## Phase 1: The pre-analysis module (code, TDD)

- **Goal:** `preanalysis.py` — the ceiling, computed before any GPU spend.
- **Prerequisites:** aspects 1–3.
- **Files:**
  - New `src/whetstone/bakeoff/preanalysis.py` (stdlib-only, deterministic, offline):
    - Reads a `whetstone-autopsy/1` document (the stored autopsy outputs) and applies the
      trigger mapping (`diffcheck.trigger_of`) to each record's fine cause/detail.
    - Counts per candidate: retry-eligible (trigger causes), non-trigger remainder
      (`im-start-loop`, `end-of-output`, `well-formed`, `no-diff`, `unrecognised-shape`,
      `header-without-hunk`), and the **ceiling** — retry-eligible minus inferred
      truncation — with the definition written in the module docstring before the run
      (D-arm1).
    - Writes its document only under a gitignored root (the `autopsy.py:727-745` refusal
      pattern, adapted); CLI `python -m whetstone.bakeoff.preanalysis --autopsy PATH
      --out PATH`.
    - Its own no-inference AST walk (the established pattern).
  - New `tests/bakeoff/test_preanalysis.py` (RED first): synthetic autopsy records
    (fixtures shaped like the stored ones) — the mapping counts correctly per candidate;
    a near-zero ceiling vs a real one are distinguishable; the output document schema is
    `whetstone-preanalysis/1`; refusal under a published path.
  - Run it for real: over `runs/diff-autopsy/{arm-a,budget-2048}.json` (absolute paths);
    the ceiling document lands in `runs/format-hardening-preanalysis/` (gitignored).
- **Validation:** `uv run pytest tests/bakeoff/test_preanalysis.py`; full suite green;
  the real run's document exists with per-candidate counts.
- **Commit:** `Measure the retry-eligible ceiling before spending the arm`
- **Operator decision point (halt condition):** read the ceiling. If it is near zero, the
  arm halts here — the slice's measurement deliverable becomes the pre-analysis finding
  (PRD R5), and the report is written from it (Phase 4 still assembles
  `reports/format-hardening/` with the ceiling as the measured outcome). If the ceiling is
  material, proceed. Either way the decision is recorded in the finding.

## Edge cases / error handling

- **Arm halts at Phase 1** (ceiling near zero): the slice still ships — the pre-analysis
  finding is the deliverable; the report states it plainly (PRD R5's zero-is-publishable).
- **Autopsy finds `unrecognised-shape` in the new transcript:** a taxonomy correction,
  not a pass — the new shapes are read and the instrument's taxonomy extended in `autopsy.py`
  (not frozen), with the completeness contract re-asserted; the divergence is reported, never
  reconciled.
- **The run fails mid-way** (provisioning, workspace): the AC7 discipline makes the rerun
  per-task checkable (journal + transcript); the journal's divergence machinery reports
  what the comparison can and cannot say.
- **Token spend exceeds the baseline arm's:** expected (up to 3 draws); disclosed per arm,
  never hidden in the comparison.
