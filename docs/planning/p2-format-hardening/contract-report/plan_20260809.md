## Edge cases / error handling

- The committed baseline `report.json` was written by the old five-field writer — the new
  dataclass must parse it (Phase 1 test) or every offline reader breaks.
- The guard's list extension is the *permission* — if the D6 argument is not honest at
  review, the fallback (PRD D4) is a second contract section inside `reports/baseline/`;
  that is a review-gate decision, not an implementation choice.
- `retrieval` as a field must not be populated from a default that hides a contract
  difference — it is written explicitly per contract (`"oracle"` today, asserted in the
  report test).
