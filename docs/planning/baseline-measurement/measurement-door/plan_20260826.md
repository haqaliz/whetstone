## Edge cases & error handling

- A stub engine that never reaches the generator (`UNPROVISIONED`/`NO_ORACLE`) has no
  recorded completion → never retried (the `_CompletionRecorder.completion() is None`
  boundary, `gate.py:806-815`) — inherited by identity, asserted in a test.
- The evidence document is written only after scoring completes; a killed run leaves no
  artifact (stated, never idempotence).
- `--out` and `--runs` are disjoint by role: the committed artifact (refused under gitignored
  roots) vs the run evidence (refused under published roots) — both directions asserted.
