## Edge cases & error handling

- A hand-edited artifact (count changed, digest stale) is refused by the loader — the
  measured-once discipline's read side; the render side refuses a same-series re-render.
- The declaration state is a *generated* committed artifact — the no-count assertion walks
  all three files (a declaration with a figure is the pre-run lie, refused by test).
- The evidence pointer is a digest, never contents — a canary planted in a task cannot reach
  the artifact.
