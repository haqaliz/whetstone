## What the build changed about the spec

**Three things, each found by running it.**

1. **The runs root must contain nothing but nights** (plus the gate's `promotions/`). The first
   `--verify` test put the report's output inside the runs root and the scan refused it —
   correctly. The test's tree was unrealistic, not the code: reports go to `reports/local/`. The
   fixture now uses the real layout, and says why in its docstring.

2. **`cli.py`'s docstring guard tripped on my own correction note.** The note quoted the false
   sentence it was correcting, and the guard cannot tell a quotation from a live claim. The note
   was reworded to *describe* the old sentence rather than reproduce it — because a guard that
   punishes recording a correction teaches people to delete their corrections, which is the
   opposite of what this repository wants.

3. **The docstring matcher was too literal**: the night's subcommand is `run`, spelled
   ``run --night`` in the prose, which is how an operator types it.
