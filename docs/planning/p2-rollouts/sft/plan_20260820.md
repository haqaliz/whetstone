# Plan — sft (aspect 2 of p2-rollouts)

**Spec:** `spec.md` · **PRD:** `../prd.md` · **Written:** 2026-08-20

## Shape

`loop/sft.py`, with every `mlx` import function-local (the `mlx_runtime.py` discipline) so the
module imports, type-checks and tests on a machine with no extra. The training call is behind a
`Trainer` seam — the same inversion `run.Engine` makes — so the whole aspect is exercised with no
weights, no GPU and no network.

## Declared before the run (never after)

- `CAPACITY_PROBE_ITERS = 8` training steps; `MACHINE_BYTES = 36 GiB`;
  `CAPACITY_HEADROOM_BYTES = 0.85 × MACHINE_BYTES`. A probe whose measured peak exceeds the
  headroom is a **published capacity finding**, not a knob to turn.
- The pre-committed fallback, decided here and not after seeing a number:
  `GRAD_CHECKPOINT = True` and `GRAD_ACCUMULATION_STEPS = 4` are on from the first probe;
  if the probe still exceeds headroom the night halts. Never a smaller base.
- `TrainingArgs` fixed at construction and recorded in provenance: batch size, iters,
  max sequence length, learning rate, LoRA layers, adapter file.
- `VALID_FRACTION = 0.1`, `VALID_FLOOR = 2` examples. Below the floor there is **no valid split**
  and the checkpoint's provenance states `no valid split (strict-PASS set below floor)` verbatim.

## Phases

1. Dataset writer (mlx-lm local format: `train.jsonl`, `valid.jsonl`) + the pure parser test.
2. Capacity probe record + its declared-values assertion.
3. Train invocation behind the seam; provenance and the weights-style re-hash `verify_checkpoint`.
4. The two refusals: a zero-strict-PASS night writes no checkpoint; a silently-validated
   checkpoint (a valid split below the floor that is not declared) is refused by a test.

## Acceptance mapping

AC1–AC5 → `tests/loop/test_sft.py`; AC3b's adapter round-trip is a loudly-skipped test on a
machine without the `mlx` extra. AC6 → CI.
