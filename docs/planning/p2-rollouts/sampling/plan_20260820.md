# Plan — sampling (aspect 1 of p2-rollouts)

**Spec:** `spec.md` · **PRD:** `../prd.md` · **Written:** 2026-08-20 · **Branch:** `feat/p2-rollouts/aliz`

## Shape

A new package `src/whetstone/loop/`, EXEMPT on the `bakeoff` precedent. Nothing under
`bakeoff/` moves; everything the loop needs is composed **by identity** (`freeze`, `Sealed`,
`Recording`, `Retry`, `probe`, `harness_status`, `rankable`, `score`, `Journal`, `Transcript`,
`report.tally`'s `Outcome.SOLVED`, `load_weights`).

## Phases

1. **Partition first.** `tests/test_reward_path_scope_is_partitioned.py` gains a `loop` entry in
   `EXEMPT` with a written reason, and the one-way assertion at the foot of that file is widened
   from `whetstone.bakeoff` to *both* exempt packages. Watched failing before the package exists.
2. **Seeds.** `loop/sampling.py`: `K = 8` (declared, never a run knob), `attempt_seed(run_seed,
   task_id, attempt)` over **sha256** — never the builtin `hash`, which is salted per process and
   would make the determinism criterion a property of `PYTHONHASHSEED`. `Draw` is a `Generator`
   wrapper that resolves the task from the frozen `posed` map (the `run.Recording` mechanism),
   applies the seed through an injected `Seeder`, records what it applied, and delegates.
3. **k draws, one control.** `loop/draws.py`: per task, one `control.probe` and `K` `score` calls,
   each behind its own `Draw`; a `Sweep` is assembled per draw index from the shared probe so
   `rankable` gates each draw by identity. One `Journal` and one `Transcript` **per draw index**,
   because both are keyed `(candidate, task)` and k draws would otherwise collide.
4. **Selection.** `loop/dataset.py`: `Outcome.SOLVED` **and** a recorded `Status.PASS`, with the
   complement enumerated as a constant so the partition over `Outcome` is asserted complete.
5. **Ledger.** `loop/ledger.py`: schema `whetstone-run/1` — run seed, `K`, every applied
   per-attempt seed, model revision, task set, tool versions, per-source counts, unverified,
   coverage, dataset digest. Hashes and verdicts, never contents; a canary asserts no donor source
   text can reach it.
6. **Determinism.** Two runs of the same seed over the same stub table produce byte-identical
   dataset documents and byte-identical `train.jsonl`.
