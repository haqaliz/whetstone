# Plan — night-door (aspect 3 of p2-rollouts)

**Spec:** `spec.md` · **PRD:** `../prd.md` · **Written:** 2026-08-20

## Shape

`loop/night.py` composes aspects 1–2 and builds nothing new. `cli.py` gains one subcommand,
`run --night`, whose body is a **function-local** import of `whetstone.loop.night` — the only
edge from a guarded root into an exempt package in this repository, and the one-way assertion is
extended to prove it is the only one and that it is function-local.

## The `--out` question, resolved

The spec asks for both "`runs/<id>/` holds journal, ledger, dataset and transcript" and "the
transcript is refused under `--out`". Those cannot both be literal: `runs/` **is** the gitignored
evidence root, so refusing the transcript under it would refuse the documented layout. The
resolution, stated rather than papered over:

- The door takes `--runs` and `--checkpoints`, both required, both documented gitignored roots.
  It creates `<runs>/<id>/` and `<checkpoints>/<id>/`.
- The locality property is kept in the form that is coherent and is **stronger** than the literal
  one: the door refuses a run root or checkpoint root that resolves inside a committed `reports/`
  directory, raising `run.TranscriptNotPrivate` **imported by identity**, so the refusal
  vocabulary stays single. A test asserts both documented homes are gitignored, on the
  `test_transcript_locality.py` precedent.

## Phases

1. Subcommand + parser in `cli.py`; `--night` is required, because `run` with nothing behind it
   would be a command that exits 0 having done nothing.
2. `night.run_night`: weights re-hash → stratum-free task partition → dev overlay → freeze (with
   retries) → per-task control + `K` seeded draws → per-draw `rankable` → dataset → ledger →
   capacity probe → SFT → checkpoint.
3. Exit codes: a night that wrote a candidate is 0; anything else reduces through
   `whetstone.verify.verdict.reduce` and **can never be 0**; refusals are 2.
4. Runbook at `runbook.md` + guard `tests/test_night_runbook_guards.py`, watched failing against a
   deliberately wrong stub sheet, on the `test_larger_base_runbook_guards.py` precedent.
