## Edge cases & error handling

- `seeds` absent vs `seeds: []` — both are "empty" (exit 1); an absent key is a doctored
  document, and `payload.get("seeds")` returning `None`/`[]` is refused by the same condition
  (refuse-or-decide, never default).
- `draws_recorded` absent entirely → `IncompleteRun` (the count check catches it).
- A `draws_recorded` entry whose `harness` lacks a source key → `IncompleteRun` (missing
  source), never a silent skip.
- Journal path collision: always derive via `evidence_paths` by identity — never re-type the
  `draw-{attempt:02d}` format string.

## Agent execution notes

- The module must read the ledger **raw** (`ledger.read`), not `morning.read_ledger` — the
  decision needs `draws_recorded` and `seeds`, which the typed reader does not carry.
- Do not parse journal content; existence only.
- The `REFUSALS` tuple must end with a trailing `ValueError` (the `honest_report` precedent,
  honest_report.py:112-114) so an unforeseen crash is a named exit-2, never a traceback.
