## Edge cases & error handling

- A refusal must print only to stderr and return `USAGE_ERROR`; a violation is printed to
  stdout via `disclosure` and returns `FAIL_EXIT`. Never a traceback.
- `--run` is required: missing it is argparse's usage error (exit 2), covered by the flag
  surface.
- The new edge is function-local for the same reason the other four are: `whetstone verify`
  never executes it, and `mlx_lm` stays off the reward path even transitively.
